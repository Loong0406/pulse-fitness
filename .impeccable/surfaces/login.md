# 手机号登录入口

Mode: Operate。原生 Android，直接使用 Java 与 XML 实现。

既有产品内的登录页，使用系统字体和手机号＋演示验证码流程。2026-10-26 用户明确要求全 App 改为红黑配色，登录页同步采用黑色表单、深红品牌区、红色主按钮和浅红链接，颜色以 DESIGN.md 及当前资源为准。

页面顶部为品牌与简短训练邀请，下面为手机号、验证码、主登录按钮、游客入口、可阅读的协议链接及明确的本机演示说明。不使用没有配置的微信登录按钮、不声称短信已发送。

首次启动进入登录页；已登录或已选择游客时进入主页。“我的”可返回登录或退出体验账号。原有档案与记录不因退出而删除，清空本机数据时一起清空身份。

验收：手机号错误、未同意协议、验证码错误或过期、连续错误、重发倒计时、旋转恢复、登录成功、游客进入、重新启动记住选择、退出与再次进入。检查键盘、安全区、1.3 字号和深色主题；不创建额外盘符，不启动模型服务。
