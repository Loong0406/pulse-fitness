脉动 PULSE 隐私说明（演示版）

更新日期：2026 年 10 月 26 日

1. 手机号和演示验证码
仅当你输入手机号并选择登录时，当前演示流程才会使用该号码。不发送短信，不请求读取短信或通讯录权限。默认本机模式的验证码在设备内生成；勾选服务端保存后，验证码由你配置的 Java 服务生成并在页面展示。验证码只临时保留用于校验，不写入用户表。两种模式都不验证真实手机号所有权。游客体验不要求手机号。

2. 本机保存的信息
演示登录状态、手机号、个人档案、训练计划、训练记录和收藏保存在 App 私有存储中。页面中的手机号以部分隐藏形式显示。演示账号与游客模式共用本机训练资料，不提供多账号数据隔离或云端同步。

3. 网络访问
默认本机登录不发送手机号。勾选“将手机号与登录记录保存到服务端”并同意协议后，号码、验证码和临时挑战标识会发送给你配置的 Java 服务。校验成功后该服务在 SQL 数据库保存用户 ID、完整手机号、注册和最后登录时刻，以及每次演示登录记录；真实手机号验证标识为否。训练档案、计划、收藏和训练历史仍保存在此设备，各演示身份共用它们，并未按用户隔离。只有主动使用所配置的 AI 服务时，相关训练档案才会发送到该网关；网关调用上游模型前移除昵称和性别。

4. 连接令牌
若你保存网关访问令牌，该令牌由 Android Keystore 加密保护。模型服务的 API Key 应配置在服务端，不填入此登录页。

5. 删除和退出
退出登录清除本机演示身份，保留训练资料；在“我的”选择“清除本机所有个人数据”会清除本机身份、档案、训练记录、收藏和连接设置。此操作不会删除你所配置服务数据库中的用户和登录记录；这些数据需由该服务的管理者处理。应用已关闭系统云备份及设备迁移。
